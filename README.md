# Lähiön Aarre

Mobiilille optimoitu digitaalinen hot-seat-lautapeli 2–4 pelaajalle.

## Pelaa GitHub Pagesissa

Kun GitHub Pages on käytössä `main`-branchin juuresta, peli avautuu osoitteessa:

`https://arto-arto.github.io/lahion-aarre/`

## Pelaaminen

1. Valitse 2–4 pelaajaa.
2. Heitä noppaa ja liiku kartalla hohtavia reittiruutuja pitkin.
3. Tutki punaisia kätköjä.
4. Etsi Stigun avain.
5. Avaa Stigun metsäkätkö.
6. Palaa aarteen kanssa omaan kotipesään.

## iPhone

Peli toimii Safarissa ja voidaan lisätä Koti-valikkoon:
**Jaa → Lisää Koti-valikkoon**.

## Tekniikka

Staattinen HTML/CSS/JavaScript. Ei backendia eikä build-vaihetta.
